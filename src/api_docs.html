StreamStatus API

The official REST API for the InfosecStreams community. Secure, lightning fast, and updated via Webhooks in real-time.

GET /api/status Public

Legacy Endpoint: Retrieves all streamers as a mapped JSON object (keys are usernames). Primarily used by the original frontend app.

Rate Limit: 5 requests per second per IP.

cURL 
curl -X GET https://streamstatus.wupinyin.co.uk/api/status
GET /api/streamers Public

New RESTful Endpoint: Retrieves a JSON array of streamers. You can pass a status query parameter to effortlessly filter the results without needing extra parsing logic.

All Streamers 
curl -X GET https://streamstatus.wupinyin.co.uk/api/streamers
Online Streamers Only 
curl -X GET https://streamstatus.wupinyin.co.uk/api/streamers?status=online
Offline (Inactive) Streamers Only 
curl -X GET https://streamstatus.wupinyin.co.uk/api/streamers?status=offline
Response (JSON Array) 
[
  {
    "username": "discomouse",
    "is_online": true,
    "game": "Science & Technology",
    "language": "en",
    "tags": ["cybersecurity", "infosec"]
  }
]
POST /api/streamers Admin Only

Registers a new streamer in the database and automatically negotiates an EventSub webhook subscription with Twitch. Requires the administrative Bearer token.

cURL 
curl -X POST https://streamstatus.wupinyin.co.uk/api/streamers \
  -H "Authorization: Bearer <YOUR_SS_ADMIN_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"username": "SomeStreamer"}'
